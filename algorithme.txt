Algorithme : Résolution de ax² + bx + c = 0
Variables : a, b, c, d, x1, x2 : réels

Début
    Saisir a, b, c
    d ← b² - 4*a*c

    Si d < 0 Alors
        Afficher "Pas de solution réelle"

    Sinon Si d > 0 Alors
        x1 ← (-b - (racine d)) / (2*a)
        x2 ← (-b + (racined)) / (2*a)
        Afficher "Deux solutions : x1 = ", x1, " et x2 = ", x2

    Sinon   (d = 0)
        x1 ← -b / (2*a)
        Afficher "Une solution double : x = ", x1

    FinSi
